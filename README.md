# devops-polifarmasi-project
Polifarmasi RAG projesi

Proje Hakkında
 Bu proje;çoklu ilaç kullanımında yaşanabilecek etken madde çatışmalarında erken bir görü sağlayan,doktor veyahut hastanın görebileceği ve yapılırsa e-nabız'a entegre edilebilir bir projedir.
 RAG (Retrieval-Augmented Generation) ise LLM halüsinasyonlarını engelleyebilmek içindir. RAG (retrieval-augmented generation), yapay zeka sistemlerinin daha doğru yanıtlar üretmek için harici bilgi kaynaklarından ilgili bilgileri alıp kullanmasının bir yolunu temsil eder.
 RAG, yalnızca eğitim verilerine güvenmek yerine, yanıtlar oluşturmadan önce gerçek zamanlı verileri (belgelerden veya veritabanlarından) kullanır.
  Hasta ve doktorlar için geliştirilmesi planlanmıştır.

## Çalıştırma Adımları ve Özelliği Deneme
Projeyi yerel ortamınızda çalıştırmak ve test etmek için:
1. Depoyu klonlayın: `git clone https://github.com/rozac603-cmyk/devops-polifarmasi-project.git`
2. Gerekli bağımlılıkları yükleyin ve `streamlit run app.py` komutuyla arayüzü başlatın.
3. İlaç listesini girerek RAG modelinin ürettiği etkileşim raporunu gözlemleyin.
